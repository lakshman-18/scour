# Code of conduct

scour is a small, friendly project. Everyone taking part (issues, pull requests, discussions) agrees to:

- **Be kind and assume good intent.** Critique code and ideas, never people.
- **Be welcoming.** Newcomers' questions are good questions. No harassment, insults or discrimination of any kind.
- **Keep it on topic and constructive.** Explain the problem, suggest a fix, share what you tried.
- **Respect the project's limits.** Requests to add CAPTCHA solving, anti-bot evasion or personal-data
  harvesting will be closed; they're out of scope by design.

If someone breaks these, the maintainers may edit or remove their contributions and block them. To report a
problem privately, use GitHub's **Report content** option or contact the maintainer through their GitHub profile.
